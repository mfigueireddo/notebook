# VERSIONS_CRITERIA.md

## Critério de versionamento

Este projeto segue o modelo Semantic Versioning (SemVer), no formato `MAJOR.MINOR.PATCH`.

| Posição | Quando incrementar |
| --- | --- |
| `MAJOR` | Mudanças incompatíveis com versões anteriores |
| `MINOR` | Novas funcionalidades compatíveis com versões anteriores |
| `PATCH` | Correções de bugs compatíveis com versões anteriores |

Enquanto `MAJOR` for `0`, o projeto está em desenvolvimento inicial e a API/estrutura pode mudar a qualquer momento, mesmo em incrementos de `MINOR`.
